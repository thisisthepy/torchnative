FAQ자주 묻는 질문

Can I install it next to PyTorch?PyTorch 와 같이 설치할 수 있나요?

No. The wheel provides torch itself, so there is one torch per interpreter. Upstream PyTorch is only a test-time comparison baseline here.

아니요. 휠이 torch 자체를 제공하므로 인터프리터마다 torch 는 하나입니다. 여기서 upstream PyTorch 는 테스트 때의 비교 기준일 뿐입니다.

Why not torch.compile?왜 torch.compile 이 안 되나요?

Dynamo's frame hook needs CPython internals that cannot coexist with the limited API, and the limited API is what lets one binary per platform serve 3.13 and every later CPython. torch.export is the direction instead.

Dynamo 의 프레임 훅은 제한 API 와 공존할 수 없는 CPython 내부를 요구하는데, 그 제한 API 가 플랫폼당 바이너리 하나로 3.13 이후 모든 CPython 을 지원하게 합니다. 대신 torch.export 방향으로 갑니다.

Is it faster than PyTorch?PyTorch 보다 빠른가요?

Not the point, and the last numbers are stale. Long-sequence prefill was slower in float32 and faster in bfloat16; decode with a KV cache was about even. They will be re-measured on an idle machine before being quoted again.

그것이 목적은 아니고, 마지막 숫자도 낡았습니다. 긴 시퀀스 prefill 은 float32 에서 느렸고 bfloat16 에서 빨랐으며, KV 캐시 디코드는 비슷했습니다. 다시 인용하기 전에 유휴 기계에서 재측정합니다.

Which Python?어떤 파이썬인가요?

CPython 3.13 or later. Wheels are cp313-abi3; Pyodide (WASM) is the exception, tied to one CPython.

CPython 3.13 이상. 휠은 cp313-abi3 이고, Pyodide(WASM)만 예외로 한 CPython 에 묶입니다.
